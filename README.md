# 📊 Housing Market Analysis & Prediction Portfolio

Welcome to my Streamlit portfolio! This application is designed to provide a **thorough** analysis of the Boston Housing dataset, combining interactive data visualization with machine learning predictions.

## 🚀 Project Overview
The primary goal of this project is to **accomplish** a deep understanding of the factors influencing property values. By analyzing socio-economic data, this app provides **intuitive** insights into how various variables **outweigh** each other in determining market prices.

## 🛠️ Key Features
- **Interactive Dashboard:** Explore the relationship between variables (e.g., Rooms vs. Price) using **rigorous** data visualization powered by Plotly.
- **Predictive Modeling:** A dedicated section to generate house price estimates **derived** from our regression logic.
- **Professional Resume:** An integrated 'About Me' section highlighting my technical expertise and analysis philosophy.

## 📂 Project Structure
- `app.py`: The main application script containing the Streamlit layout and logic.
- `data/boston.csv`: The primary dataset containing housing features and median values.
- `asset/`: Directory containing visual elements such as profile photos.
- `requirements.txt`: A **sufficient** list of dependencies required to run the environment.

## 💻 Technical Stack
- **Language:** Python
- **Framework:** Streamlit
- **Data Manipulation:** Pandas, Numpy
- **Visualization:** Plotly Express
- **Analysis:** Regression Modeling
